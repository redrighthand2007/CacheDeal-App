## [Unreleased]

### 🚀 Added
- Initial project setup with Jetpack Compose + Material 3
- Firebase integration (Auth, Firestore, Storage)
- Phone OTP authentication flow
- User profile with hostel/block selection
- Item listing with photo upload
- Category-based browsing feed
- "Near Me" proximity filter
- Cash offer submission system
- Seller offer review screen (sorted by price)
- Deal acceptance with atomic batch writes
- WhatsApp deep link for post-deal communication
- "Mark as Completed" flow with 3-day window
- Green/Red dot reputation system
- Auto re-list on missed completion
- Dark mode Material 3 theme

### 🏗️ Infrastructure
- MVVM + Clean Architecture
- Hilt dependency injection
- Type-safe Compose Navigation
- GitHub Actions CI/CD pipeline
- Firestore security rules
